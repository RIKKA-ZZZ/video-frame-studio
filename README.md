# 取帧工作台

用浏览器从本地视频中导出一张原始尺寸的图片。视频在设备上解码，无需上传。

1. 点击「打开视频」，或将文件拖入预览区。
2. 拖动时间轴定位画面，也可输入时间（如 `00:04.250`）后按回车。左右方向键每次微调 0.1 秒。
3. 选择 PNG、JPG 或 WebP，点击「导出当前帧」。

网站自带一段可试用的生成式山景视频。文件的可读取性取决于浏览器支持的编码。也可以下载源码并双击 `index.html` 离线使用。

本项目由静态 HTML、CSS、JavaScript 和素材构成。GitHub Pages 从 `main` 分支的根目录发布，无需安装依赖或构建。
